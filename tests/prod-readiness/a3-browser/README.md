# A3 frontend production-readiness checks

These tests import the production Vue components and Axios transport. The browser runner temporarily copies its entry point into ignored `web/node_modules/.a3-prod-readiness`; no test route or synthetic data enters the production bundle. It starts Vite and Playwright in the same process tree, then removes the temporary entry point and stops Vite.

## Run

```sh
pnpm --dir web install --offline --frozen-lockfile
pnpm --dir web typecheck
pnpm --dir web lint
pnpm --dir web test
pnpm --dir web build
node --test tests/prod-readiness/a3-browser/core.test.mjs
python3 tests/prod-readiness/a3-browser/run.py
```

`run.py` uses Playwright's installed Chromium by default. `SCM_UI_CHROMIUM=/absolute/path/to/chromium-headless-shell` selects an existing compatible executable without changing sandbox settings. Install Python Playwright and its browser in environments that do not already provide them.

Artifacts are written to ignored `target/test-artifacts/a3/`: JSON results, screenshots, and the local Vite log. They must not be committed. All request bodies and users in the runner are synthetic.

The core tests also preserve `9007199254740993` and reject out-of-range BIGINT routes; ID fields, selectors, route parameters and actor fields use strings, while page sizes, counts, versions, quantities and local UI counters remain numeric.

Every page in every browser context records uncaught page errors and console errors. Only the exact injected resource paths/statuses and the local `ModuleBoundary` UUID log are classified as expected faults. The artifact retains both expected and unexpected error records/counts; any other console error fails the run. Fault injection deliberately produces console errors, so passing does not mean an empty console.

## Integration prerequisites

- A1's decimal-string ID responses, idempotent route list and `/api/stock-logs/seek` must be integrated with this frontend. The whitelist deliberately does not infer idempotency from the presence of a UUID header.
- Cookie refresh remains explicitly disabled in production until A2's agreed server session rotation is installed. Root owns enabling and validating that integration.
- Financial visibility and contact permissions are a separate follow-up change using the latest domain permission contract; they are not asserted by this performance fixture.
