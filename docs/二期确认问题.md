# 二期要确认的问题

11-21 整理。二期是甲方需求表里标成二期的 P1 功能（PRD §2.2）。这份分三块：不用确认、我们先做的；要甲方答的；已经答了、不用再问的。

要甲方答的每条都写了"现在的打算"：不答就照它做，或者先不做。答了以后改 PRD，编号对应 PRD §12。

## 一、不用确认，先做的

要做什么 PRD 里已经写清楚，数据一期也都有了，只剩我们自己的设计取舍。照下面的顺序做，做完一块发一块。

| 功能 | 编号 | 做成什么样 |
|---|---|---|
| 订单进度总览 | 06.07 | 一屏看所有在手的需求订单，每个款到了哪一步：排产、齐料、各生产单的当前节点、回货、还剩几天。先看到有问题的 |
| 翻单 / 补单 | 06.05 | 在一张历史订单上点"翻单"或"补单"，款和明细都带过来，改数量和交期就行；新单记住是从哪张单来的 |
| 基础资料、款式的改动记录 | 01.08、02.05 | 物料、供应商、款式、仓库等档案的"操作记录"里，能看到每次改了哪个字段、改前是什么、改后是什么 |
| 进销存汇总表 | 07.07 | 按物料、按月：期初、本期入、本期出、期末，能按仓库筛、能导出 |

## 二、要甲方答的

### Q26 研发打样留哪些环节（二期 M03）

11-18 甲方说要精简：研发阶段只留样衣的基础信息，后面的都到转大货时再填。11-21 这条标了黄、没写答复，所以要约一次面谈。面谈前请想一下：

1. 样衣要记哪些信息？比如图片、设计师、品类、面料说明、打样日期、样衣编号。
2. 要不要"打样单"，在系统里给版房派活？
3. 打样进度（制版、裁剪、车缝、完成）要不要在系统里跟？
4. 样衣评审（通过、修改、不要了）要不要在系统里记？谁来评？
5. 一个样衣改了几版，要不要记版次？
6. 样衣的出入库、借出、归还、库存要不要管？领猫里这块有 6 个菜单。
7. 转大货时，样衣的哪些信息带到款式上？（一个样衣能转几个款，11-18 已经答了。）

现在的打算：只做样衣档案和"转成款式"，别的等面谈。

### Q55 工厂料账：耗料按什么算（二期 07.09、08.07）

料账要算出每张外发加工单"应该用掉多少料"，再和领了多少比，多出来的退回、少了的算超耗。

1. 按**良品**算（回货 − 次品）还是按**回货数**算（含次品）？
   - 按良品：没修回来的次品、裁了没交的，用掉的料都算成工厂的超耗。
   - 按回货数：次品修好以后会再登记一次，同一件就算了两遍。
2. 超耗了要不要从加工费里扣？（扣钱等对账结算模块做，现在只记数量和原因。）

现在的打算：按良品算；超耗只记数量和原因。

### Q56 吊牌、水洗唛、包装资料（二期 04.06）

一期款式上有吊牌价、品名、成分、执行标准、安全类别；11-21 加了"功能吊牌"。

1. 吊牌、水洗唛上印的内容，现在是谁出、用什么格式发给印刷厂的？能给一份样本吗？
2. 系统要做到哪一步？只存资料就行，还是要导出给印刷厂的文件？
3. 洗护符号要不要从国标图标里选？
4. 装箱规格（每箱几件、箱子尺寸、怎么混码）要不要记？记了给谁用？

现在的打算：款式上存一份完整的吊牌、水洗唛资料，导出 Excel 给印刷厂；装箱规格先不做。

### Q57 生产单资料包（二期，PRD §6.4.7）

领猫有"生产资料包"：下外发加工单时，把生产 BOM 复制一份到这张单上，可以按这一批微调，比如这批换一种面料、改一下用量。

1. 你们会按批次改用量、换料吗？多不多？
2. 现在遇到这种情况怎么处理？

现在的打算：不做。整个款都要改的，修订资料包；只是这一张订单要改的，走需求订单的变更单。

### Q58 请购单（二期 07.02）

一期的做法：算料的结果就是采购需求，采购单审核就是审批。备货用"补货提醒"一键生成采购单。

1. 除了算料算出来的，还有哪些东西要买？谁提出来？比如样衣用的面料、包材备货、办公耗材。
2. 提出来以后要谁批？批完由谁下采购单？

现在的打算：不做独立的请购单。样衣用料等研发打样定下来以后一起看。

### Q59 货位（二期 07.07）

1. 仓库里分货位吗（几排几层）？哪几个仓要分？
2. 入库、领料时要选货位吗？盘点要按货位盘吗？

现在的打算：不分货位。库存表已经留了货位这一列，以后要分不用改表。

### Q60 工厂产能与负荷（二期 08.02）

1. 一家工厂的产能怎么算？按"件 / 天"就行，还是不同品类分开算（外套和 T 恤差很多）？
2. 产能数谁来维护？多久更新一次？
3. 排单时工厂排满了，是拦住不让排，还是只提示一下？

现在的打算：每家工厂一个日产能（件 / 天）。排单时显示这家工厂到交期之前手上有多少件在做、能做多少件，只提示不拦。

### Q61 二次加工、外协（二期 08.04）

1. 有哪些二次加工？比如印花、绣花、洗水、压胶。是你们发给印绣花厂，还是加工厂自己找人做？
2. 发出去的是裁片还是成衣？要不要跟数量（发了多少、回了多少、损耗多少）？
3. 费用是单独和二次加工厂结，还是含在加工费里？
4. 只在外发加工单上多跟几个进度节点就够了，还是要单独开一张"二次加工单"？

现在的打算：在外发加工单的进度节点里加"二次加工"，只跟进度，不单独开单。

### Q62 字段权限（二期 13.01）

已经做了的：看采购价、成本要"看成本"权限，看销售价要"看订单销售价"权限，银行账号只显示后几位。

1. 还有哪些字段，某些角色不能看？比如供应商的联系人、电话、地址。
2. 11-21 还没答的两条：跟单、生产经理能不能看供应商的联系方式？"理单"这个角色做什么事？

现在的打算：照现在的做。联系方式所有能看供应商的人都看得到。

### Q63 不同主体公司的库存要分开算吗（二期 01.01）

一期主体公司只是单据上的一个字段：数据按品类线隔离，库存不按主体分。

1. 不同主体公司的料，库存要不要分开算？比如 A 公司买的料，B 公司的单能不能领？
2. 要不要按主体公司分别出报表？

现在的打算：不分，库存是公共的。真要分得在导入期初库存之前定，导完再分要重新核对期初。

### Q64 审批：按条件换人审、会签（二期 13.03）

一期已经能按金额加一级审批：采购单超过 5 万、加工单超过 10 万，加一级总经理审。

1. 还有哪些情况要换人审、或者多加一个人审？比如按品类线、按部门、新供应商的第一张单。
2. 有没有要几个人都同意才算通过的（会签）？是哪些单？

现在的打算：不做，只按金额加一级。

### Q65 消息推送和手机审批（二期 13.04、13.05）

1. 公司用钉钉吗？推送走钉钉的话，要甲方的钉钉管理员在钉钉开放平台建一个应用，把应用的 Key 交给部署方，放进服务器配置。
2. 推哪些消息？比如：轮到我审了、我的单被驳回了、货期预警、到料逾期、待核销耗料。
3. 在手机上要能直接审核吗？还是看到消息、回电脑上处理就行？

现在的打算：钉钉工作通知推"轮到我审""被驳回"两种，点进来是手机上的审核页。

### Q66 报表看板、预警中心（二期 13.06、13.07）

1. 现在每周、每月要看哪些表？给几张你们现在做的样表最准。
2. 下面这些要哪些？
   - 采购到货及时率；
   - 工厂交期达成率、次品率；
   - 各品类线在做的件数；
   - 订单毛利（要先有成本）；
   - 呆滞料。
3. 预警现在分散在首页待办、待到料、生产看板里。要不要一个统一的"预警中心"？还要加哪些预警？

现在的打算：进销存汇总表先做（见第一块），别的等样表。

## 三、已经答了、不用再问的

- 客供料核销（07.05）：客供料这块收起来了，等以后要做代工再开（11-11）。
- 合同、供应商风险排查（Q22、Q23）、智能助手（Q45）：还在等甲方给时间，问题不变。
