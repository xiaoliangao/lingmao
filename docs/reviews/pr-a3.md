## 问题与改动

长驻业务页面在发版、弱网和并发读取下容易出现白屏、迟到响应覆盖、重复提交或录入丢失。本阶段冻结请求身份与版本、隔离刷新与写动作、限制长列表渲染，并保留局部失败后的导航和恢复操作。

本次属于四阶段独立交付，按 A1 → A3 → A2 → A4 叠放。前端 Cookie 刷新生产启用、财务字段权限和异步导出由 A2 集成；统一 CI、审计与生命周期在 A4 完成。`main` 不修改、不合并。
