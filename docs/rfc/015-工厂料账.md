# RFC 015 工厂料账（委外发料跟踪、发料与回货平衡）

状态：**草案**（11-21），等用户审。

对应：PRD §2.2 的 07.09、08.07（二期），§6.1.6 工厂仓，§6.6.5 出入库类型，§6.7.7；RFC 010 §1"工厂仓 = 净托管账面量"；docs/api/04、05、06。

## 1. 解决什么

甲方需求表的原话：

- 07.09 委外发料与外发物料跟踪："外协环节的料与货能对上账"。
- 08.07 发料与成品回收平衡（工厂料账对冲）："发出多少料、收回多少货，一一对账"。
- 领料 / 退料 / 调拨："工厂手上的料清楚，防止物料流失"。

一期现在：领料从物料仓进工厂仓，退料从工厂仓出。工厂仓的数叫"净托管账面量"，只加不扣：工厂做完衣服用掉的料，不从账上扣。后果有两个：

1. 账面一直涨。一张单领 990.86 米、用掉 981.178 米、退回 9.682 米以后，工厂仓还挂着 981.178 米。几个月下来，工厂仓的数就没法看了。
2. 看不出哪张单多用了料。甲方要盘工厂仓（11-20 说期初每个工厂仓都点一次），盘出来的差全记成"盘亏"，分不出哪些是正常用掉的、哪些是丢的。

这次做三件事：

1. **每张生产单一本料账**：领了多少、按良品该用掉多少、结余多少（就是该退回来的）。做完货以后"核销"一次。
2. **核销 = 一张新类型的物料出库单"耗料核销"**：从工厂仓扣掉这张单用掉的料，审核时过账。核销完，工厂仓的账面就是工厂手上应该有的料。以后再盘工厂仓，盘出来的差才是真少了。
3. **"工厂料账"页**：按生产单看，哪些还没核销、哪些超耗了；按工厂看，每种料账上有多少、其中多少会被在做的单用掉、估计工厂手上还剩多少。

这次不做：

- 扣工厂的钱（超耗折成钱、从加工费里扣）：等对账结算模块（待定）。这次只记数量，超耗要写原因。
- 一张单分几次核销：交完货一次核销（§9 取舍 4）。
- 直发工厂仓的料分到生产单（§9 取舍 5，§11 第 5 条）。
- 工厂剩的料直接转给下一张单用、不退回（§11 第 5 条的"顺带"）。
- 客供料核销（TRADE 收起），二次加工（08.04）发出去的裁片和成衣。

## 2. 口径

**应耗**：按良品算，这张单该用掉多少料（库存单位）。

> 应耗 = 良品 × 单件用量 ×（1 + 损耗率）

- 良品 = 已回 − 次品，每个款式 SKU 一个数。和生产单"回没回齐"用同一个口径（甲方 11-19：次品退回去返修，修好的再登记）。
- 用量、损耗率、对到哪个物料 SKU，都和"应领"一样：取锁定的生产 BOM 里物料来源 = 自购的行，按颜色、尺码对到物料 SKU（docs/api/05 §3.4.1），只是件数换成良品。
- 成品采购单也这么算（它的自购料通常只有主唛、吊牌、包装袋）。

为什么按良品、不按回货数：回货数里含次品。次品修好后会再登记一次，按回货数算，同一件就算了两遍。没修回来的次品、裁了没交的，料都是工厂用掉的，所以算进超耗。要不要让工厂担，看超耗原因（§11 第 1 条，要问甲方）。

**已领**：领料出库 − 退料入库（只算挂了这张单、已审核的），和现在一样。

**实耗**：核销单上填的数，默认等于应耗。工厂说多用了，可以改大；改大的那行要写超耗原因（和领料的"超领原因"一样）。

**超耗** = 实耗 − 应耗，大于 0 才显示。

**结余** = 已领 − 实耗；还没核销时用应耗来估。

- 大于 0：工厂该退回来的，开退料入库。
- 小于 0：这张单用的料比领的多，多出来的是从工厂仓里别的料出的（直发的、别的单剩的）。

例子（PRD §4.3）：卡其 400 件（S 80、M 120、L 120、XL 60、XXL 20），卡其布分码用量 2.25 / 2.35 / 2.45 / 2.55 / 2.65 米，损耗 3%。应领 962 × 1.03 = 990.86 米，领料领了 990.86 米。回货 400 件，其中次品 4 件；假设 4 件都是 M 码，良品 M 码 116 件。应耗 =（962 − 4 × 2.35）× 1.03 = 952.6 × 1.03 = 981.178 米。

- 按应耗核销：工厂仓扣 981.178 米，结余 9.682 米。开退料入库退回来以后，工厂仓的这块布就是 0。
- 工厂说用了 985 米：实耗改成 985，写超耗原因"色差重裁 2 件"。超耗 3.822 米，结余 5.86 米。

**料账状态**：不存，查询时算。

| 状态 | 条件 |
|---|---|
| 在制 | 生产单是已下单、生产中 |
| 待核销 | 已完成、已结案，没有耗料核销单，而且应耗或已领不是 0 |
| 核销中 | 有一张草稿的耗料核销单 |
| 已核销 | 耗料核销单已审核 |

没有自购料、也没领过料的生产单不进料账（成品采购单经常是这样）。

## 3. 耗料核销单

物料出库单加一种类型 `CONSUME_OUT`（耗料核销）：

- 出仓是工厂仓，就是生产单上加工厂的那个，不能改；没有入仓。往来单位是加工厂。源单必须是生产单（外发加工单、成品采购单都行），不能手建。
- 过账时工厂仓减。现在的过账只看单上有没有出仓、入仓，不用为这个类型加 if。工厂仓不够扣，照常报 1001"工厂仓 ×× 库存不够"。这说明工厂仓的账对不上：料被调走了，或者直发的料没入库。先查清楚（调拨、补入库、盘点），或者把实耗改小。
- 流程和别的出库单一样：存草稿 → 别人审核过账（不能审自己建的，Q10）→ 能反审核、作废。权限也一样：新建要 `inventory:doc:add`，审核要 `inventory:doc:audit`，现在只有仓管有这两个。
- 一张生产单同时只能有一张没作废的耗料核销单，靠部分唯一索引兜底。
- 明细可以删行。一行都不剩时要写原因，意思是"这张单没有要扣的料"。比如结案时一件没做、料全留给下一张单，或者 BOM 写了自购、料其实没经过工厂仓。这种空单也要审核，留着记录，以后也能反审核。

**从哪里开**：

- 生产单详情的"领料"页签（改名"领料 · 料账"）加一个按钮"核销耗料"。生产单已完成或已结案、还没核销、当前用户有 `inventory:doc:add` 时才出。
- 物料出库单页的"新建"里加"耗料核销（选生产单）"，列出待核销的单。

两个入口都打开现有的"由源单生成"对话框。每行：物料、已领、应耗、工厂仓库存、本次（默认等于应耗）、超耗原因（本次大于应耗才出）、备注。

**生产单这边的规则**（写在 `ProductionStockHandler` 里，在 inventory 的事务里调）：

- 带出、存草稿、审核时，都先锁生产单这一行，和登记回货排队。
  - 生产单不是已完成、已结案：报 1000"外发加工单 JG… 还没完成，交完货再核销"。
  - 已经有别的没作废的核销单：报 1000"已经有耗料核销单 CK…"。
- 反审核不拦。核销单不会改生产单的状态。
- 有没作废的核销单时，生产单不能登记回货、不能作废回货单、不能取消结案（取消结案会回到生产中，又能登记回货）。报 1000"已经开了耗料核销单 CK…；要改回货，草稿先删掉，已审核的先反审核再作废"。这几件事都会改良品数，应耗跟着变，核销单上的数就不对了。
- 核销以后退料：退料入库的上限从"已领"改成"已领 − 实耗"，不小于 0。
- 已结案的单也能退料。现在只有已下单、生产中、已完成的能退；结案后工厂把剩料退回来是常事。退料入库在已结案时也能反审核。

不回写任何字段：料账全是查询时算的，核销单过账不改生产单、也不改算料单。领料状态、"订单都领完料时算料单自动关闭"只看领料和退料，和核销无关。

## 4. 页面

### 4.1 生产单详情的"领料 · 料账"页签

现有的表（物料、应领、已领、还差、物料仓库存）后面加三列：应耗、实耗（核销后才有）、结余。结余大于 0 显示琥珀色"该退 n"，小于 0 显示灰色"多用 n"。

表上方一行字：良品 n 件 · 料账状态 · 核销单号（点了去出库单详情）。

按钮：领料、退料（这两个现在就有）、核销耗料。

### 4.2 工厂料账页（生产 › 工厂料账，`/factory-ledger`）

照列表页的样子：`PageHeader` → `FilterBar` → 表。顶上分段切换两个视图：按生产单 / 按工厂物料。

**按生产单**（默认）：

- `#left` 的分段：待核销（默认）/ 核销中 / 已核销 / 在制 / 全部，每段带数。
- 筛选：加工厂、种类（外发加工 / 成品采购）、完成日期；关键词搜单号、款号。
- 列：生产单号（固定在左）、种类、加工厂、款号、款名、加工数、良品、生产状态、料账状态、超耗（几种料超了）、该退（几种料还有结余）、核销单号。点一行去这张生产单的"领料 · 料账"页签。
- 不做批量核销：每张都要看一眼实耗。

**按工厂物料**：

- 筛选：加工厂；关键词搜物料。
- 每个工厂仓 × 物料 SKU 一行：加工厂、物料编码、名称、颜色、规格、单位、账面（工厂仓现在的库存）、未核销的耗料、估计手上、涉及几张单。
  - 未核销的耗料：这个工厂所有还没核销的单（在制、待核销、核销中），按目前的良品算出来的应耗加起来。
  - 估计手上 = 账面 − 未核销的耗料。小于 0 标红，说明工厂用的比账上多：直发的料没入库、料被调走了，或者超耗了没报。
  - 点一行去库存日志，筛这个工厂仓、这个物料。
- 只列账面不是 0、或者未核销的耗料不是 0 的行。
- 能导出，发给工厂对账。

### 4.3 库存页、首页

- 首页"其他提醒"加一个"待核销耗料"（`CONSUME_PENDING`）：待核销的生产单张数。有 `inventory:doc:add` 的人才看得到，点了跳 `/factory-ledger?status=TO_SETTLE`。

## 5. 接口

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/api/production-orders/{id}/materials` | 现有 | 每行加 `consumeQty`（应耗）、`settledQty`（实耗，没核销是 null）、`balanceQty`（结余）；外层加 `goodQty`、`ledgerStatus`、`settleDoc`（核销单的 id、单号、状态，没有是 null） |
| GET | `/api/production-orders/issue-options?settle=true` | 现有 | 列待核销的单（`returnable` 不动） |
| GET / POST | `/api/inventory-docs/from-production/{id}?docType=CONSUME_OUT` | 现有 | 带出：每行 `suggestQty` = 应耗，`maxQty` = null，`issuedQty` = 已领；出仓固定是工厂仓 |
| GET | `/api/factory-ledger/orders` | `production:ledger:list` | 按生产单，返回 `PageResult<LedgerOrderRow>`。参数：`keyword`、`status`、`factoryId`、`kind`、完成日期起止 |
| GET | `/api/factory-ledger/orders/counts` | 同上 | 每种料账状态各有几张 |
| GET | `/api/factory-ledger/materials` | 同上 | 按工厂物料，返回 `PageResult<LedgerMaterialRow>`。参数：`factoryId`、`keyword` |
| GET | `/api/factory-ledger/materials/export` | `production:ledger:export` | 导出按工厂物料的视图 |

错误码：

- 1000：生产单状态不对、已经有核销单、核销后还要改回货。
- 1001：工厂仓库存不够。
- 400：超耗了没写原因；空的核销单没写原因。

数据范围：

- 按生产单：照生产单的数据范围和品类线，和外发加工单列表一样。
- 按工厂物料：是仓库的数，和库存页一样不按人筛。"未核销的耗料"是所有单加起来的合计，只出数，不列单据。

## 6. 表结构（V50）

不加表。

```sql
-- 一张生产单同时只有一张没作废的耗料核销单
CREATE UNIQUE INDEX uk_inv_doc_consume ON inv_doc (source_id)
    WHERE doc_type = 'CONSUME_OUT' AND status <> 'VOIDED';

COMMENT ON COLUMN inv_doc_item.over_reason IS '超领原因（领料出库）/ 超耗原因（耗料核销）：超过建议数时必填';

-- 菜单：生产 › 工厂料账 /factory-ledger，按钮 production:ledger:list、production:ledger:export
-- 授权：生产经理、生产跟单、仓管、管理层、财务（看、导出）
```

`inv_doc.doc_type` 是 VARCHAR(16)，没有 CHECK 约束，加类型不用改列。

## 8. 并发

- 核销单带出、存草稿、审核都锁生产单这一行（`FOR UPDATE`）；登记回货、作废回货单、取消结案本来就锁它。所以一边登记回货、一边开核销单，两件事会排队，后到的能看到先到的结果。
- 两个人同时开核销单：部分唯一索引挡住第二张，报错翻成 1000"已经有耗料核销单"。
- 工厂仓扣减用现有的条件更新，不够扣就报 1001。

## 9. 取舍

1. **只出报表、不扣工厂仓**：没选。工厂仓的账面只涨不降，期初盘过的工厂仓，几个月后数就没法看。盘工厂仓时，耗料全记成盘亏，分不出是正常用掉还是丢了。
2. **登记回货时自动扣料**：没选。回货是跟单登的。工厂仓料不够（直发没入库、料被调走）时，要么拦住回货（不能因为料账不对就不让登记交货），要么扣成负数（库存不允许负数）。一张单要回好几次货，每次一张扣料单，账很碎；次品修好再回来，还得冲回去。
3. **实耗不让改，只按标准扣**：没选。工厂实际多用的料（报废、色差重裁），就看不出是哪张单用的，要等盘点时才在工厂这一级冒出来。
4. **一张单分几次核销**：先不做。大单分批交货，交完再核销。真要分批，以后再加"这次核销到第几件"。
5. **直发的料分到生产单**：先不做。采购单的行是挂在算料单上的，一张算料单管几张订单，没法自动认出是哪张生产单的。工厂这一级的账是平的：直发入库进了工厂仓账面，核销也从工厂仓扣。按单看时，直发料那一行会显示"多用 n"，表头写一句提示。

- 单测：
  - 料账状态、结余正负（纯函数）。
  - `ProductionStockHandler`：生产单没完成报 1000；已经有核销单报 1000；带出的数按良品算。
  - 回货：有核销单时登记回货、作废回货单都报 1000。
  - 接口测试 1 个（`FactoryLedgerController`）。
- `FactoryLedgerIT`，真库上走一遍例子：
  1. 领料 990.86 → 回货 400、M 码次品 4 → 带出应耗 981.178。
  2. 实耗填 985、不写原因：400。写了原因 → 存草稿 → 自己审被拦 → 换人审 → 工厂仓 990.86 − 985 = 5.86。
  3. 再登记回货：1000。
  4. 退料 6：1004（超上限 5.86）。退料 5.86：成功，工厂仓变 0。
  5. 反审核核销单 → 作废 → 又能登记回货了。
  6. 两个人同时开核销单，只成一张。
  7. 工厂仓不够扣：1001。
  8. 空的核销单：不写原因 400，写了能审。
  9. "按工厂物料"的估计手上，和在做的单对得上。
- 前端：生产单的料账页签、工厂料账的两个视图、出库单的新类型，在页面上点一遍。

## 11. 等用户定的

1. **应耗按良品（推荐），还是按回货数（含次品）**。按良品的话，没修回来的次品、裁了没交的料，都显示成超耗。这条也要问甲方，PRD 加一个 Q55。
2. **核销要不要扣工厂仓**。推荐扣（§9 取舍 1）。
3. **核销以后不能再登记回货、作废回货单、取消结案，要先撤掉核销单**。推荐这样。
4. **已结案的单能不能退料**。推荐能。
5. **直发工厂仓的料这次不分到生产单**。推荐这样。
   - 顺带一个一期就有的问题：面料直发工厂时，生产单的"领料"页签会一直显示"还差"，跟单可能会再领一次。要不要以后加"采购入库进工厂仓时，选给哪张生产单"，单独排。
   - 工厂剩料留给下一张单用：现在只能先退料入库、再领料出库，开两张单。以后可以在领料对话框里提示"工厂仓里已经有 n"，或者加"转单"。
6. **谁开、谁审**：和物料出库单一样，仓管开，另一个仓管审（Q10）。甲方要是只有一个仓管，就给生产经理加上出库单的审核权限（在角色页勾一下就行）。
7. **菜单位置**：放在"生产"下面，生产经理、跟单、仓管、管理层、财务能看。
