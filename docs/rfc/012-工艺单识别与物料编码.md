# RFC 012 工艺单识别、物料清单分工、物料编码

状态：**草案，等用户审**（11-18）。两样东西要等甲方给：工艺单统一模板（§2）、物料编码新规则（§4）。没给之前只能定机制，具体的格子位置、编码段落到时补进本文。

对应：PRD v0.25 §6.4、§6.1、§12 的 Q05、Q47、Q48、Q49；RFC 011（本文推翻它的"系统不读工艺单""不生成 PDF"两条）；架构 §4.9、§8、§11.1；数据库设计 §5.5、§5.9、§9。

## 1. 解决什么

甲方 11-18 晚在确认清单上答的，用户当天定照做：

| 问题 | 甲方答 | 用户定 |
|---|---|---|
| Q47 工艺单 | 模板统一成一种（版师定），上传后系统识别尺寸表、车间缝制工艺、后道（还提到料耗），存成数据后面能用；能导出 PDF 给工厂、直接分享 | 照最新答复做；PDF 也加上，模板后面给 |
| Q49 物料清单 | 面辅料归研发，耗材归生产 | 选 B：研发填面辅料的行，生产填耗材的行 |
| Q05 物料编码 | 物料、辅料、耗材、包材的编码规则要重新定；想要一个外部编码和领猫对应，再要一个供应商编码方便和供应商对 | 新系统统一用新规则编码；领猫导进来的物料留着原来的编码 |
| 字段反馈 | 物料加"面料功能""是否带吊牌"；不同 SKU 能填不同单价；颜色编码只能 2 位字母；尺码号型不能改，老款翻新换了尺码只能换款号；资料包填用量的地方要能一键填写 | 本文逐条给做法 |

不在本文（下一份 RFC 013）：品类线隔离（Q13、Q30）、一级审批和生产经理（Q10）、排单回货超 5% 和裁床数（Q09）。这几条跨所有模块，单独写。

## 2. 工艺单识别（Q47）

### 2.1 流程

1. 版师照统一模板写工艺单 Excel，在资料包草稿的"工艺单"页签上传（和现在一样，RFC 011 §2）。
2. 上传后点"识别"（工艺单组里每个 Excel 旁边一个按钮；只有一个 Excel 时上传完自动识别）。后端只解析、不写库，返回识别结果。
3. 弹窗预览识别结果：尺寸表、车间缝制、后道几块，认不出的格子标出来（和 BOM 导入的预览一样，RFC 011 §4.3）。点"用这份"填进页面上的草稿。
4. 点"保存"才存，跟着这个版本走。生效以后只读，要改就修订、重新上传、重新识别。

识别出来的东西在"工艺单"页签上文件列表下面显示成几块：尺寸表（部位 × 尺码，带公差、测量方法）、车间缝制、后道。

### 2.2 Excel 和系统里的数据谁说了算

**建议：Excel 说了算，系统里的数据只读。** 要改就改 Excel、重新上传、重新识别。理由：

- 两边都能改，很快就对不上：工厂拿到的 PDF 是系统数据生成的，版师手里改的是 Excel。
- 版师已经习惯在 Excel 里写；系统里再做一套编辑器（尺寸表、分段文字、插图）就是 11-14 那版的工作量，11-18 刚去掉。

要用户定：识别错了个别格子，允不允许在系统里直接改（改了就和 Excel 不一样了）。默认不允许。

### 2.3 存什么

照模板设计，模板到了再定列。先按甲方说的三块留出结构（参考 V20 的 `tp_spec_point`、`tp_spec_value`、`tp_craft_section`，V39 删了，代码在 ad9c2dd 之前的提交里）：

| 表 | 一行是什么 | 主要列 |
|---|---|---|
| `tp_size_chart_row` | 尺寸表的一个部位 | 资料包、顺序、部位、测量方法、公差（±） |
| `tp_size_chart_value` | 一个部位 × 一个尺码 | 行、尺码、数值（cm） |
| `tp_craft_block` | 车间缝制、后道里的一段 | 资料包、块（`SEWING` 车间缝制 / `FINISHING` 后道 / 以后加的）、顺序、标题、文字 |

- 尺码对不上款式的尺码组时（模板里是 S–XL，款式是 M–XXL），识别预览里标出来，存的时候只存对得上的；对不上的一律不让"用这份"，要么改 Excel，要么改款式。
- 工艺单里的图（缝制示意图）：先不拆进系统，PDF 里照原样带上 Excel 里的图（`ExcelPreview` 已经能读图）。要不要拆成每段一张图，看模板。
- **料耗**：甲方说识别"工艺尺寸、料耗、工艺"。BOM 用量已经在物料清单里（从 BOM 表导入或手填）。建议料耗只做核对：识别出来和物料清单的用量比，不一样的在预览里标黄，不覆盖物料清单。要模板到了看料耗写在哪、写的是什么。
- 迁移：新的 `V4x`。这几张表现在没有数据，建表不涉及"只增不删"。

### 2.4 导出 PDF

用户定 PDF 加回来，模板后面给。

- 在资料包详情"更多"里，和生产单"更多 › 工艺单"里，导出这个版本的 PDF。
- 内容照甲方给的 PDF 模板排；没给之前按 11-17 做过的那版排：表头（款号、款名、版本、生效日期、主图）、尺寸表、车间缝制、后道、物料清单（不带价格）、工艺单 Excel 里的图。
- 技术上把 ad9c2dd 删掉的 `common/pdf/PdfRenderer`（openhtmltopdf + PDFBox）和 Noto Sans SC 字体（`dev/fetch-font.sh`，镜像里带字体）恢复回来，架构 §11.1 照 v0.15 写回去。
- 没识别过的版本（只有上传的文件）：PDF 只有表头和物料清单，页面提示"工艺单还没识别"。

### 2.5 分享给工厂

甲方问"能不能直接分享"。两种：

- **A（建议，一期）**：手机上下载 PDF，用系统的分享面板发微信（和现在下载工艺单一样，PRD §6.4.4 规则 3）。
- **B**：生成一个不用登录的链接，几天后失效，工厂在微信里点开看 PDF。上传文件已经是签名地址（架构 §8），技术上不难；但链接转出去谁都能看，要甲方同意。放二期，和工厂账号（Q02）一起定。

### 2.6 纸样（Q48 的追问）

甲方问"是否可以转换版本？（改版之后版型可能变化，需要有核实的动作）"。

- 系统不转换纸样格式（.prj、.plt 是打版软件自己的格式），只存、只下载。
- 核实：修订出新版本时纸样文件跟着带过去。新版本生效时，如果纸样和上一版是同一份文件（没换过），生效确认框里多一句"纸样和 V{n} 一样，版型没改过吗？"，点"没改，生效"才生效。不拦，只提醒。

## 3. 物料清单研发和生产分工（Q49 选 B）

### 3.1 哪些行归谁

按**物料类型**分，每个物料类型设"物料清单里谁填"：研发或生产。

- 甲方说的"面辅料"和"耗材"在系统里没有对应的类型：现在的物料类型是面料、里料、辅料、包材、标签吊牌、配件、工艺、鞋底（Q40）。
- **要问甲方：哪些类型算耗材。** 没答之前的默认：包材归生产，其余归研发。缝纫线、胶袋这种如果建的是"辅料"，要么甲方加一个"耗材"类型，要么改它的类型。
- 存法：字典 `material_type` 每一项的 `text_value` 写 `DEV` 或 `PROD`（空 = `DEV`）。这一列 V39 以后没有字典在用，正好留着给"字典带一段文字"用（数据库设计 §3.2）。设置 › 字典里物料类型多一列"物料清单谁填"。

### 3.2 权限

- 新加两个按钮权限：`techpack:bom:dev`（填研发的行）、`techpack:bom:prod`（填生产的行）。`techpack:pack:edit` 还管版本备注、工艺单文件、核价这些整版的东西。
- 默认：开发、开发主管有 `dev`；生产跟单有 `prod` 和 `techpack:pack:edit`（现在生产跟单对资料包只能看，PRD §3.1 的角色表要改）。
- 页面上：物料清单分成两块，"面辅料（研发填）"和"耗材（生产填）"，没有权限的那块只读。加行时物料弹窗只列自己能填的类型。
- 后端兜底：保存时按服务端认出的行身份比对，改了没权限的那一块的行（加、删、改用量、改物料）报 403，做法和看不见价格的人改不了价格一样（`PackFinancialAccess`）。
- 从 BOM 表导入：只有一种权限的人导，不归他的行在预览里标"归生产填，不导"（或反过来）。两种都有的照常导。

### 3.3 流程

**建议：同一份草稿，研发填完面辅料、生产填完耗材，再生效。**

- 谁生效不变（开发，有 `techpack:pack:publish` 的人）。生效时耗材那块是空的，确认框提醒一句"耗材还没填"，不拦（有的款确实没有耗材）。
- 生效以后要补耗材，和改面辅料一样修订出新版本。需求订单锁的是版本，算料按锁定版本的物料清单算，所以生效以后不能悄悄改。

另一种做法是耗材生效以后还能单独改、不出新版本。不建议：算料、领料按版本算，同一个版本前后两次算出来不一样，对不上账。

## 4. 物料编码（Q05）

### 4.1 编码

- 新规则甲方后面给（物料、辅料、耗材、包材可能各有规则）。到了以后改 `MaterialServiceImpl.nextCode`（现在是"分类码 + 4 位流水"），段落照规则拼；本文到时补上规则。
- SKU 编码不变：物料编码-颜色码[-规格码]。颜色码 2 位字母（§5.3）。

### 4.2 领猫的老编码

用户定"新系统统一用新规则编码，领猫导进来的保留原来的编码"。**建议这样理解：**

- 导进来的物料**也按新规则发一个新编码**，作为系统里的编码（单据、库存、BOM 上显示的都是它）；
- 领猫的老编码存进新列 `bas_material.legacy_code`（"领猫编码"），SKU 一样存 `bas_material_sku.legacy_code`。
- 所有按编码搜的地方（物料库、选物料弹窗、⌘K、BOM 导入、期初库存导入）都同时搜老编码；详情页显示"领猫编码 XXX"。
- 以后从领猫导的东西（期初库存、款式的 BOM）按老编码对上。

这就是甲方说的"外部编码作为对应关系跟领猫衔接"。

另一种理解：导进来的物料直接用领猫编码当系统编码，只有新建的用新规则。这样系统里两套编码混着，甲方 11-18 也说了新旧规则冲突时要取舍，所以不建议。**要用户确认是哪一种。**

- 试用环境：如果物料已经按领猫编码导进去了，换成新编码时写一个一次性的迁移：老编码挪进 `legacy_code`，按新规则发新编码；物料还没被单据引用时最省事。上线前导正式数据时直接按新规则导。

### 4.3 供应商编码

甲方要"再增加一个供应商编码能跟供应商方便对接"。现在已经有：物料的"供应商货号"、SKU 的"供应商货号""供应商色号"（数据库设计 §5.9、§5.10），采购单上也带出来。**建议不加新字段**，试用时给甲方看这几个是不是他们要的。

## 5. 主数据的几处小改

### 5.1 面料功能、是否带吊牌

现在这两个是领猫附加属性，导入时原样存在 `legacy_attrs` 里，只读显示（数据库设计 §1.8）。改成物料的正式字段：

| 字段 | 存法 | 页面 |
|---|---|---|
| 面料功能 | `bas_material.fabric_functions`，JSONB 数组；选项是新字典 `fabric_function`（防水、抗菌……甲方自己加） | 物料表单多选，物料库能按它筛；物料类型是面料、里料时才显示 |
| 是否带吊牌 | `bas_material.with_tag` BOOLEAN，空 = 没填 | 物料表单是 / 否 |

- 导入：领猫的这两列进正式字段，不再进 `legacy_attrs`。已经存在 `legacy_attrs` 里的，迁移时挪过来。
- **要问甲方："是否带吊牌"指的是什么。** 物料上带吊牌不太常见，可能是指某种成品料（如配件）自带吊牌，也可能是领猫里别的意思。没答之前只记录、能筛选，不参与任何规则。

### 5.2 不同 SKU 不同单价

已经有：SKU 上有单价，空着用物料的参考单价；新建物料时每个颜色一行能顺手填（PRD §6.1.5）。不改，试用时给甲方看。

### 5.3 颜色编码 2 位字母

- 新建颜色只收 2 位字母（现在是 2–3 位字母或数字），存大写。
- 建好不能改，现在就是（编码进了 SKU 码）。
- 导入：领猫导进来的颜色编码照原样（它们已经在领猫的 SKU 编码里了）；不是 2 位字母的列在导入结果里提醒，不拦。数据库列 `VARCHAR(3)` 不改。

### 5.4 尺码号型不能改

甲方说"老款翻新尺码号型更改时不能更改，只能换款号"。现在已经是：款式生成了 SKU 就不能换尺码组（`StyleServiceImpl`）；尺码组建好以后已有尺码的顺序、基码不能改，只能在后面加（RFC 003）。

要加的：款式详情"更多"里一个"复制成新款"，带着款名、品类、颜色、图片和最新生效的资料包（复制成新款的草稿），尺码组可以换、款号重新发。老款翻新换尺码时用。

### 5.5 用量一键填写

甲方说"标准资料包填用量的地方需要可以一键填写"。没说清是哪种，建议两样都做，都是页面上的事：

1. **分码用量一键填满**：分码的行展开"尺码 → 用量"，填了基码以后点"各码一样"，其余尺码填成同一个数，再逐个改。
2. **勾几行批量填**：物料清单勾几行，底部批量条"填用量 / 填损耗"，一次填一个数。

**要问甲方是哪一种**，或者两种都要。

## 7. 测试

- 识别：照模板造一份假的工艺单 Excel（不用甲方原件），认出尺寸表、车间缝制、后道；尺码对不上、缺块的报出来。
- PDF：中文字、尺寸表分页、没识别过的版本。
- 分工：只有 `dev` 的人改耗材行 403，反过来一样；导入时不归自己的行不导；生效时耗材空着只提醒。
- 编码：导入后老编码能搜到、能对上期初库存；新建按新规则。
- 颜色：3 位、带数字的新建报错；导入的照收、提醒。

## 8. 要用户定的

1. 识别出来的数据只读、Excel 说了算（§2.2）。
2. 分享先只做下载发微信，不登录的链接放二期（§2.5）。
3. 研发、生产在同一份草稿里填，生效以后改耗材也要修订（§3.3）。
4. 导进来的领猫物料也发新编码，老编码存在"领猫编码"里（§4.2）。**这条和你说的"旧系统导入的依然保留原来的编码"可能理解得不一样，请确认。**
5. 不加新的供应商编码字段，用现有的供应商货号、色号（§4.3）。
6. "复制成新款"这次一起做（§5.4）。

要问甲方的：工艺单统一模板和 PDF 模板（§2）；料耗写在模板哪里（§2.3）；哪些物料类型算耗材（§3.1）；物料编码新规则（§4.1）；"是否带吊牌"指什么（§5.1）；用量一键填写是哪一种（§5.5）；鞋类的 BOM 表（PRD Q49）。
