一、上线前要答 12 月中旬上线

Q21

正式服务器用哪台、谁来装

谁答：IT · 装服务器要时间，越早越好

现在大家试用的系统装在我们这边的电脑上，只是试用。正式使用要装在你们的服务器上；装好以后，把试用期间录的数据整体搬过去，再开始用。

要问的

  1. 用哪台服务器？公司机房的，还是云服务器（阿里云、腾讯云等）？

  2. 服务器的 CPU 是哪一种？安装包要按它来打。

    • Ax86（Intel、AMD，最常见）
    • BARM（比如华为鲲鹏、阿里倚天）
    • C不清楚，问一下服务器的供应商

  3. 谁来装、以后谁来升级？我们每周发一个升级包，照手册执行一条命令就行，我们可以远程协助。

  4. 要不要在公司外面（手机上、出差时）打开系统？要的话，有没有已经 ICP 备案的域名？

不答就这样做

你们准备一台 x86 服务器（2 核 4G 内存、40G 硬盘起，装 Linux 和 Docker），最晚上线前一周照部署手册装好，我们远程协助。装好后把试用环境的数据搬过去，演练一次从备份恢复，再正式启用。安装包自带全部程序，服务器不用连外网下载。从外面访问用已备案的域名，走 HTTPS。

Q54

上线那天怎么切：领猫哪天停录、期初库存谁点

谁答：生产、采购、仓管、财务 · 上线前开会定

你们说过：先拿一单试跑，没问题再切；旧单在领猫里做完。期初库存是在库存页点「导入期初库存」录进来的：每个仓库点一次实盘，导进来、另一个人审核以后，就是开账的数。

要问的

  1. 领猫哪天停录新单？从那天起，新单只在新系统里录。

  2. 期初库存哪天点？谁点、谁核对签字？

  3. 放在加工厂的我方面料（工厂仓）也一起点吗？

    • A一起点，工厂里的料也进系统
    • B不点，工厂仓从零开始，以后发过去的才记

  4. 旧单在领猫做完以后剩下的料，什么时候补录进新系统？

不答就这样做

开会约一个截止日。截止日每个仓库（包括工厂仓）点一次实盘，导进系统，你们核对签字后开始用。旧单剩下的料，等旧单做完再补录。

Q14

账号名单、岗位权限、每个环节谁来审

谁答：管理层 · 试用开始前

你们定了：自己建的单不能自己审，要另一个有审核权限的人审。审核权限是角色上的一个勾（下图）。所以如果某个环节只有一个人有审核权限，比如只有一个仓管，他建的单就没人能审，只能找超级管理员。

要问的

  1. 账号名单能给我们吗？要每个人的姓名、岗位、管哪几条品类线（服装、鞋类、百货）。你们说过从领猫导出一份，还没收到。

  2. 下面这些单，每种至少要两个人能审。各由谁审？

    • 需求订单、订单变更
    • 采购单
    • 外发加工单、成品采购单
    • 物料入库单、物料出库单
    • 物料盘点单
    • 供应商准入、供应商关键信息的改动

  3. 「理单」这个岗位做什么事？你们说过理单的人建物料、做物料入库单和出库单，还做别的吗？我们照它配一个「理单」角色。

  4. 供应商的联系人、电话、微信、地址，现在生产跟单和生产经理都能看，对吗？

    • A两个都能看
    • B生产经理能看，跟单不能看
    • C两个都不能看
不答就这样做

按岗位预设的权限开账号：需求订单、变更、采购单、加工单、盘点单由生产经理和管理层审，物料入库、出库单由仓管审，供应商准入由管理层批。哪个环节只有一个人能审，我们就给生产经理也勾上。「理单」先照"建物料、做出入库单、不审核"配。跟单、生产经理照现在都能看供应商联系方式。

要问的

  1. 哪几家公司会在这些单据上用到？

  2. 每家在系统里叫什么简称？

不答就这样做

Q63

不同主体公司的库存要不要分开

谁答：财务 · 导期初库存之前要定

现在主体公司只是单据上的一个字段（Q11 截图里采购单上的「主体」）。数据按品类线隔开，库存不按主体公司分。

要问的

  1. 不同主体公司的料，库存要不要分开算？比如 A 公司买的料，B 公司的单能不能领？

    • A不分，料是公共的，谁的单都能领
    • B分开，各领各的

  2. 要不要按主体公司分别出报表？

不答就这样做

不分，库存是公共的。真要分，得在导入期初库存之前定；导完再分，要重新核对期初。

  2. 尺寸表以后固定哪个方向？

    • A号型一行、部位一列
    • B部位一行、号型一列

  3. 导出给工厂的 PDF 照哪个版式？

    • A一页纸的老格式

Q52

谁答：采购 · 上线前

系统按"物料 + 供应商"记价格：采购单审核时遇到新报价或调了价，自动记一笔，同一种料几家供应商各有各的现价（下图）。领猫里也有这张报价表，但 11-14 给的导出里它是空的。

要问的

  1. 领猫里这张报价表你们平时维护吗？要导过来吗？

    • A不用导
    • B要导，我们重新导出一份有数据的
不答就这样做

不导。价格从上线后的单子里攒，也能在物料页手工「录价格」。要导的话我们大约花半天。

Q55

工厂料账：应耗按良品还是按回货数算

谁答：生产、财务

料账要算出每张外发加工单"应该用掉多少料"，再和领了多少比：多出来的退回，少了的算超耗。现在加工单上已经能看到应领、已领、还差（下图）。

要问的

  1. "应该用掉多少料"按什么件数算？

    • A按良品（回货 − 次品）：没修回来的次品、裁了没交的，用掉的料都算工厂超耗
    • B按回货数（含次品）：次品修好以后会再登记一次回货，同一件会算两遍

  2. 超耗了要不要从加工费里扣？

    • A要扣（扣钱等对账结算那块做，现在先记数量和原因）
    • B不扣，记下来就行
不答就这样做

按良品算；超耗只记数量和原因。

Q57

会不会按批次改用量、换料

谁答：生产

领猫有"生产资料包"：下外发加工单时，把生产 BOM 复制一份到这张单上，可以按这一批微调，比如换一种面料、改一下用量。现在系统里，需求订单审核时锁定这个款当时生效的那一版资料包，排出来的加工单跟着这一版走（见 Q61 截图右边「资料包 生产 V1」）。

要问的

  1. 你们会按批次改用量、换料吗？多不多？

  2. 现在遇到这种情况怎么处理？

不答就这样做

不做。换料、改用量都修订这个款的资料包，已经审核的订单用变更单切到新版；只改某一张单、款本身不改的，系统里做不到，线下处理。

Q58

要问的

  2. 提出来以后要谁批？批完由谁下采购单？

不答就这样做

Q60

工厂产能怎么算

谁答：生产

生产看板能按单看、按工厂看在做的单（下图）。产能还没有：系统不知道一家工厂一天能做多少件。

要问的

  1. 一家工厂的产能怎么算？

    • A一个数：件 / 天
    • B按品类分开算（外套和 T 恤差很多）

  2. 产能数谁来维护？多久更新一次？

  3. 排单时工厂排满了怎么办？

    • A提示一下，还能排
    • B拦住，不让排
不答就这样做

每家工厂一个日产能（件 / 天）。排单时显示这家工厂到交期之前手上有多少件在做、还能做多少件，只提示不拦。

Q61

二次加工（印花、绣花、洗水）怎么跟

谁答：生产

  2. 发出去的是裁片还是成衣？要不要跟数量（发了多少、回了多少、损耗多少）？

  3. 费用是单独和二次加工厂结，还是含在加工费里？

  4. 要做到哪一步？

    • A在加工单上多跟一个"二次加工"节点就够
